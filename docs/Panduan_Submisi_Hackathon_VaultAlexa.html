📝 Babak 2: Jawaban Formulir Submisi Devpost (Tinggal Copy-Paste)

Gunakan format Bahasa Inggris profesional berikut untuk mengisi formulir pendaftaran Devpost / Hackathon:

1. Project Title & Tagline

  • Title: VaultAlexa+ : Autonomous Multi-Agent Financial Advisor & Intelligent Shopping Assistant
  • Tagline: Enterprise-grade Alexa+ agent powered by Model Context Protocol (MCP Spec 2025-11-25) and AWS Bedrock for budget-safe voice commerce, bilateral seller negotiation, and proactive cashflow protection.

2. Inspiration

As voice shopping on Alexa becomes seamless, consumers face a growing friction: unintentional budget overspending and lack of pre-purchase financial visibility. We built VaultAlexa+ to act as an intelligent autonomous guardian—empowering users to shop Prime deals with confidence while proactively protecting their savings goals and recurring obligations.

3. What it Does (Key Capabilities)

  • 11 Enterprise Multi-Agent Tools: Covers the entire commerce lifecycle—from pre-purchase runway forecast (predict_monthly_runway), bilateral seller discount bargaining (negotiate_dynamic_discount), to automated post-purchase dispute & instant escrow refunds (initiate_purchase_dispute).
  • Proactive Deficit Protection: Powered by AWS Bedrock AgentCore and Amazon Forecast heuristics, identifying pending utility/insurance bills due in 5-7 days before checkouts.
  • Two-Sided Bilateral Bridge: Empowers everyday Buyers (safe-to-spend limits, household bill splitting) and verified Amazon Sellers (Prime promotion optimization & conversion analytics).
  • Developer & Regulatory Observability: Built-in live MCP Protocol Inspector delivering sub-15ms JSON-RPC 2.0 telemetry and Amazon CloudWatch audit trails.

4. How We Built It (AWS Cloud Architecture)

  • Protocol Standard: Model Context Protocol (MCP Spec 2025-11-25) over Streamable HTTP & Server-Sent Events (SSE) with TLS 1.3.
  • Compute Layer: Self-Hosted MCP Server deployed on AWS Lambda & Amazon ECS Fargate for sub-15ms stateless execution.
  • AI Orchestration: AWS Bedrock AgentCore coordinating Amazon Nova Pro and Claude 3.5 multi-agent swarm collectives.
  • Database & Storage: Amazon DynamoDB (PrimeVaultLedger table) in region us-east-1 for encrypted ledger transactions and household split pools.
  • Auditing & Telemetry: Amazon CloudWatch Logs capturing live tool execution latency and multi-agent reasoning traces.

5. Bonus Point Claims (10% Developer Feedback)

We officially submit our detailed developer feedback report in FRICTION_LOG.md, highlighting our hands-on experience with MCP HTTP SSE header resolution, rich visual card standardization, and actionable suggestions for future AWS Bedrock MCP SDK tooling.
